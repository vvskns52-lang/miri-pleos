# 미리 — 고장 나기 전에, 미리

Pleos Connect(Android Automotive OS)용 **차량 종합 안전 관리 앱**입니다.
대부분의 운전자는 정확한 정비 주기를 모르고 "고장 나면 고치는" 방식으로 차를 탑니다. 미리는 차가 보내는 신호와 운행 습관, 차종별 취급설명서를 바탕으로 소모품 상태와 경고등을 **고장 나기 전에, 말로** 알려 줍니다.

- 출품: 현대자동차그룹 차량용 앱 개발 공모전 (Pleos App Market)
- 설치 파일: [`apk/미리_release.apk`](apk/)

## 주요 기능

| 기능 | 설명 |
|---|---|
| 차종별 교환 주기 | 처음 실행할 때 "차종은 무엇인가요?"에 답하면 현대·기아·제네시스 30개 차종의 **공식 취급설명서** 주기(통상·가혹 조건)를 적용합니다. 목록에 없는 차는 일반 주기를 씁니다. |
| 소모품 14종 수명 추정 | 엔진오일, 브레이크액·패드, 변속기·감속기 오일, 에어컨·에어 필터, 냉각수, 점화플러그, 배터리, 구동벨트, 타이어, 와이퍼, 워셔액. 브레이크·에어컨·와이퍼 사용량으로 교체 시기를 앞당기거나 늦춥니다. |
| 교체 자동 감지 ① 센서 | 오일·액체 레벨 센서가 "부족 → 정상"으로 바뀌면 정차 중에 "브레이크액 교체하셨나요?"라고 묻고, 답(교체/보충/아니요)을 기록합니다. |
| 교체 자동 감지 ② 정비소 방문 | 정비소에 30분 이상 머문 뒤 "정비소에서 무엇을 교체하셨나요?"라고 묻고, 말한 부품을 모두 기록합니다. |
| 가혹 조건 자동 판정 | 짧은 거리 반복, 정체, 잦은 정지·출발을 운행 기록으로 판정해 취급설명서의 가혹 조건 주기를 자동 적용하고 근거를 보여 줍니다. |
| 함께 교체 추천 | 시기가 됐거나 곧 되는 항목을 묶어 "정비소 한 번 방문으로" 끝내도록 권합니다. |
| 말로 물어보기 | "엔진오일 언제 갈아?", "뭐 갈아야 돼?", "정비비 얼마나 들었어?", "경고등 켜졌는데 뭐야?" — 주행 중에도 말로 묻고 답을 듣습니다. |
| 경고등 안내 | 계기판 경고등 15종(엔진오일 압력, 엔진 과열, 충전, 엔진 점검, 타이어 공기압 등)이 켜지면 **주행 중에도 바로** 이름과 할 일을 말하고, 켜진 날짜·주행거리를 기록합니다. |
| 정비 비용 기록 | 교체 기록에 비용을 적으면 이번 달·올해·최근 12개월 합계와 월별·항목별 통계를 보여 줍니다. |
| 직접 추가 | 목록에 없는 부품(블랙박스, 에어컨 가스 등)도 이름과 주기를 적어 교체 기록을 남길 수 있습니다. |

운전 중에는 화면 조작을 막고(P단에서만 조작), 안내와 질문은 모두 음성으로 주고받습니다.

## 사용한 Pleos SDK

| SDK | 버전 | 용도 |
|---|---|---|
| Vehicle | 2.3.2 | 주행거리, 기어(P단), 브레이크 페달, 와이퍼, 공조, 오일·액체 레벨, 워셔액, 타이어 공기압, 경고등(telltale) |
| TextToSpeech | 3.3.1 | 음성 안내 (`ON_DEVICE`) |
| SpeechToText | 3.3.1 | 음성 답변·질문 인식 (`ON_DEVICE`) |
| FusedLocation | 1.1.3 | 정비소 방문 감지 |

조회용 퍼미션만 씁니다(`CAR_SAFETY`, `PRIVATE_CAR_SAFETY`, `CAR_DRIVE`, `CAR_WINDOWS`, `CAR_CLIMATE`, `TTS_SERVICE`, `STT_SERVICE`, `FUSED_LOCATION`). 차량을 제어하는 `CONTROL_CAR_*` 퍼미션은 선언하지 않습니다.

## 설치와 실행

Pleos Connect 에뮬레이터(v2.1.0, API 34)에서 확인했습니다. 운전자 프로필이 user 10이라 `--user 10`으로 설치합니다.

```bash
adb install --user 10 apk/미리_release.apk
```

처음 실행하면 위치·마이크·알림 권한을 묻고, 차종과 마지막 교체 시기를 고르면 대시보드가 열립니다.

### 시연 모드 (심사·발표용)

에뮬레이터는 오일 레벨, 경고등 같은 신호를 바꿀 수 없어서 숨김 시연 패널을 두었습니다. **대시보드 제목 "미리"를 5번 누르면** 열립니다.

- **데모 차량 사용**을 켜면 가짜 차량 신호로 동작합니다.
- 주행(출발/정차, +1,000km, 브레이크·와이퍼·에어컨 사용), 운행 패턴 재현(가혹 조건), 센서 부족 → 정상(교체 감지), 정비소 도착·30분 경과·떠나기, 경고등 켜기·끄기, 말로 물어보기 예시 질문(마이크 없이)을 버튼으로 재현할 수 있습니다.

## 빌드

- Android Studio, AGP 9.2.1, Kotlin 2.2.10, Jetpack Compose
- compileSdk 37 / targetSdk 34 / minSdk 28

```bash
./gradlew assembleDebug
```

```bash
./gradlew testDebugUnitTest
```

단위 테스트 132개(도메인 계산, 저장소, 엔진 시나리오)가 있습니다. 릴리스 서명 키는 저장소에 넣지 않았습니다(`~/keys/chacare-signing.properties`가 없으면 서명 없이 빌드됩니다).

## 구조

```
app/src/main/java/com/chacare/
├── domain/    순수 Kotlin 계산: 차종별 주기, 수명 추정, 가혹 조건, 함께 교체, 음성 답변, 경고등, 비용
├── data/      기기 안 JSON 파일 저장소
├── engine/    차량 신호 → 운행 기록 → 감지 → 음성 안내 (단일 스레드), 포그라운드 서비스
├── vehicle/   Pleos Vehicle SDK 연결 / 데모 차량
├── location/  Pleos FusedLocation 연결 / 데모 위치
├── voice/     Pleos TTS·STT 연결
└── ui/        Compose 화면
```

## 데이터와 개인정보

- 모든 기록은 차 안(앱 내부 저장소의 JSON 파일)에만 저장하고 외부로 보내지 않습니다.
- 위치는 정비소에 머문 시간을 재는 데만 쓰고 저장하지 않습니다.
- 교환 주기는 현대·기아·제네시스 공식 취급설명서(ownersmanual.hyundai.com, kia.com, genesis.com)의 "정기 점검" 표를 확인해 넣었습니다.

## 알려진 한계

- 정비소 방문 감지는 현재 시연용 정비소 3곳의 좌표로 동작합니다. 실제 서비스에서는 정비소 위치 데이터(POI)가 필요합니다.
- 에뮬레이터는 오일·브레이크액·변속기 오일 레벨, 워셔액, 타이어 공기압을 지원하지 않고, 켜진 경고등도 없습니다. 이 기능들은 시연 모드로 보여 드리며, 실제 차량에서는 SDK 연결 코드가 같은 경로로 동작합니다.
